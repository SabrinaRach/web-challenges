# Title
movie details page for a single chosen movie

## Value Proposition

**As a** User <br>
**I want to** have a detail page <br>
\*\*to have more information about the chosen movie <br>

## Description

when clicking on a movie I want another page to open with more details about the movie
like release date and a description
the movie poster is still displayed

## Acceptance Criteria

- new page: details page
- contains the movie title, release date, poster and description
